# 会计约束与实现边界

完整强制规则见 AGENTS.md；这里保留容易踩坑的实现事实。

- 信用卡三块：消费返利、perk 减年费/成本、已到账 SUB 减手续费/诱导消费/替代损失。Checking / savings churn 单列。主总额用 reports.report，不能拿仍含兑换价值的 core.summary.net 代替。
- 必付学费本金不是损失；2.52% 刷卡手续费可归 SUB，正常赚点归消费返利。测算不发记账事件。
- UR 与 Aeroplan 默认各 1.8¢，保留滑块/即时重算；不展示当前 UR 余额，不追踪 SUB 已消费额，旧字段留作导入兼容。目标、期限、到账状态保留。
- 余额快照无收入。earn.affectsBalance:false 只记来源/估值，不改变余额；适用于补记已含于快照的来源，也适用于 transfer.received 已含 bonus 后独立记 bonus 收入。同年仅年份来源与快照排序未知时隐藏该计划余额，不假设先后。
- 转点本金无收入；兑换价值、剩余资产与赚点估值分别显示，不叠加。飞行里程非信用卡消费返利。
- USD 税费未知（null/缺省）或现金参考价未知时不算实测 CPP；已确认零税费可用 0。保留原币金额及币种，不自动汇率换算。
- 实际 SUB earn/cashback 已记录时不再叠卡片现金摘要；未知摘要到账年份不推算开卡年份。混合或部分到账需逐笔真实事件，不推算缺口。
- 参考起价、次数和个人实际价值分离。Status 与卡片重叠只录同次使用一次并写归因；当前无独立 Status 账本/自动去重。
- Category 已按倍率/现金百分比/有效日期比较，上限仍是备注和人工维护；不得宣称自动计算剩余额度。银行未知开户日、更多 SUB 档位、扩展字段校验、买点/非卡成本口径仍在 BACKLOG。
- 具体日期、金额、周期未知时不编造。周年无锚点不推 Jan 1；结单周年与简单日历周年不同，按指定真实周期或待核对处理。
- 兼容旧 `includedInSnapshot` 的有效同计划快照 ID（以及布尔 true）；若未明确设置 `affectsBalance`，不再次增余额。新增共享 `core.earnAffectsBalance` 供余额和编辑默认值使用，原关联字段保留；回归只使用虚构快照/点数。
- 兑换可另外保留原币现金参考价、汇率日期/来源、舱位、持卡折扣与估计折扣前点数。USD 参考价和税费供现有 CPP 使用；用户提供的近似汇率要注明来源，折扣比较不另记收入，也不增加扣点事件。出行日不能冒充订票日。
